07 / Falsifiability and limitations

Measurement Notes & Self-Tests

Operational metric definitions

Tokens: Unicode word/number match; punctuation retained in a parallel sequence. N-grams never cross sentence or paragraph boundaries. Each hit retains original start/end offsets. Relative position of word i = i/(N−1) for N>1; paragraph position=(p−1)/(P−1).

f=raw hit count; relative /100=100f/available word tokens in active mode; DF=number of paragraphs with at least one hit; dispersion=DF/P. TF-IDF=mean across all paragraphs of (count/paragraph word count)×[1+ln((1+P)/(1+DF))]; burstiness=population variance of paragraph hit counts / mean (Fano factor, P≥2), not chronological burstiness.

Association=generalized independence log₂[(f/number of n-gram windows)/product(unigram frequencies/word count)], reported only when f≥2; not a semantic strength metric. Context diversity=number of distinct left/right word-neighbor pairs tagged by side divided by 2f. MATTR-50=mean TTR across overlapping 50-word windows. Lexical repetition=1−TTR.

Quantiles: sort by n-gram TYPE frequency ascending, nearest-lower rank floor[q(N−1)]. Place all tied values in the lowest eligible band: f≤qLow → Lower; else f≤qHigh → Median; else Upper. Empty bands are valid. Paragraph word-length bins use the same floor rank at 33% and 67%, or manual inclusive word-count cutoffs.

Networks: directed edges follow token order, marker→sentence occurrence, or paragraph adjacency. Edge weight=hit count (lexical/marker) or 1 (paragraph successor); discourse edges include Jaccard lexical overlap as a separate annotation. Weak connected components use the thresholded graph. Centrality shown is normalized weighted degree (endpoint strength / sum of endpoint strengths), not eigenvector or betweenness centrality.

Interpretation: surface marker matching can signal contrast/cause/negation; it cannot establish actual argument meaning, historical era, writer identity, personality, or similarity of propositions. Lexical code-switching detection is stopword-based, not trained language ID. Stop phrases are only exact contiguous word sequences. TTR comparison across unequal corpora is invalid without length control.

Capability disclosure
Implemented

Local preprocessing, original offsets, stopword ablation, bigram/trigram, KWIC, paragraph-level dispersion, TF-IDF, Fano, positional heatmap, lexical/syntax-proxy/discourse graphs, manual style overrides, four editable prompts, JSON export, clipboard fallback.

Heuristically approximated

Sentence splitting (abbreviations), ID/EN detection, category/connective markers, passive candidates, textual framing and topoi, simplified association/centrality. No estimates of classification accuracy are provided.

Requires external NLP resources

Verified POS tagging, dependency depth, entity recognition, reliable rhetorical/discourse parsing, semantics-preserving paraphrase execution and style attribution calibration.

Not implemented

Language model calls, semantic similarity scores, automatic fact checking, graph communities, diachronic authorship inference, server storage or real-time collaboration.
